
# IASM-WMS

Integrated Ashram School Management and Welfare Monitoring System.

## Objective

To develop an integrated platform for managing Ashram school administration,
student welfare, attendance, academics, hostel operations, food management,
inventory, complaints and department-level monitoring.

## Technology Stack

- Frontend: HTML, CSS, JavaScript, Bootstrap 5, Chart.js
- Backend: Python, Django, Django REST Framework
- Database: PostgreSQL
- Android: Java, XML, Retrofit, Gson
- Version Control: Git and GitHub

## Project Structure

- backend/ - Django backend and APIs
- frontend/ - Web application
- android/ - Android application
- docs/ - Requirements, design and documentation

## Development Status

Initial setup and requirements planning.
